# กฎข้อมูลรับรอง

- ชื่อผู้ใช้ยาว 3–50 ตัว ใช้ตัวอักษรอังกฤษ ตัวเลข จุด ขีดล่าง หรือขีดกลาง และไม่ซ้ำโดยไม่แยกตัวพิมพ์
- รหัสผ่านยาว 8–128 ตัว รองรับทุกองค์ประกอบโดยไม่บังคับตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข หรืออักขระพิเศษ และต้องตรวจค่าตามที่ผู้ใช้กรอกโดยไม่ตัดหรือเปลี่ยนตัวพิมพ์
- ช่องรหัสผ่านทุกช่องใช้ `type="password"`
- ค่ารหัสผ่านและยืนยันรหัสผ่านต้องตรงกันก่อนเรียก API
- JWT มีอายุ 15 นาที มี issuer, audience, subject, token identifier และชื่อผู้ใช้
- ข้อความเข้าสู่ระบบล้มเหลวต้องไม่เปิดเผยว่าชื่อผู้ใช้มีอยู่หรือไม่
- Register และ Login จำกัด 10 คำขอต่อ client IP ต่อนาทีด้วยตัวนับแยกกัน โดย Nginx เขียน `X-Forwarded-For` ใหม่จากที่อยู่ผู้เชื่อมต่อเพื่อป้องกันการปลอม header และไม่ให้การโจมตีเส้นทางหนึ่งปิดกั้นอีกเส้นทาง
- ผลตอบกลับ `/api/auth/*` ต้องมี `Cache-Control: no-store` และ `Pragma: no-cache`
