# กฎข้อมูลรับรอง

- ชื่อผู้ใช้ยาว 3–50 ตัว ใช้ตัวอักษรอังกฤษ ตัวเลข จุด ขีดล่าง หรือขีดกลาง และไม่ซ้ำโดยไม่แยกตัวพิมพ์
- รหัสผ่านยาว 8–128 ตัว ต้องมีตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ และตัวเลขอย่างน้อยอย่างละหนึ่ง
- ช่องรหัสผ่านทุกช่องใช้ `type="password"`
- ค่ารหัสผ่านและยืนยันรหัสผ่านต้องตรงกันก่อนเรียก API
- JWT มีอายุ 15 นาที มี issuer, audience, subject, token identifier และชื่อผู้ใช้
- ข้อความเข้าสู่ระบบล้มเหลวต้องไม่เปิดเผยว่าชื่อผู้ใช้มีอยู่หรือไม่
