# สมัครสมาชิกและเข้าสู่ระบบ

1. หน้า IT 02-1 รับชื่อผู้ใช้และรหัสผ่าน พร้อมลิงก์ไปหน้า IT 02-2
2. หน้า IT 02-2 รับชื่อผู้ใช้ รหัสผ่าน และยืนยันรหัสผ่าน โดยทั้งสองค่าต้องตรงกัน
3. API ต้องเก็บเฉพาะ password hash ห้ามเก็บหรือบันทึกรหัสผ่านดิบ
4. สมัครสำเร็จแล้วกลับหน้า IT 02-1
5. เข้าสู่ระบบสำเร็จแล้วได้รับ JWT และไปหน้า IT 02-3
6. หน้า IT 02-3 ต้องเรียก API ที่ตรวจ JWT แล้วจึงแสดง `Welcome User: {username}` ตามรูปแบบต้นทาง
7. การออกจากระบบต้องลบ token ฝั่งหน้าเว็บและกลับหน้า IT 02-1
