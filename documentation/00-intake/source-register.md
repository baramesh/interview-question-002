## คำตัดสินขอบเขต

- repository นี้ต้องมีข้อมูลเพียงพอสำหรับอ่าน พัฒนา รัน และตรวจงานได้ด้วยตัวเอง
- ขอบเขตผลิตภัณฑ์ประกอบด้วย Register, Sign in, JWT validation, Welcome และ Sign out
- ระบบไม่มีการเชื่อมต่อ API กับระบบธุรกิจภายนอก
- สามารถใช้ PostgreSQL server/database ที่มีอยู่ได้ แต่ระบบเป็นเจ้าของเฉพาะ schema `auth_q002`
- คำสั่งในไฟล์ Word เป็นข้อกำหนดของผลิตภัณฑ์ ไม่ใช่คำสั่งให้เผยแพร่ repository โดยอัตโนมัติ
