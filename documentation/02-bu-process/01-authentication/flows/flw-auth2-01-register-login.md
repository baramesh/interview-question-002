# ลำดับสมัครสมาชิกและเข้าสู่ระบบ

## สมัครสมาชิก

1. ผู้ใช้เปิด IT 02-1 และเลือกสมัครสมาชิก
2. ระบบเปิด IT 02-2
3. ผู้ใช้กรอกข้อมูลและกดสมัครสมาชิก
4. หน้าเว็บตรวจรูปแบบและความตรงกันของรหัสผ่าน
5. API ตรวจซ้ำ, hash รหัสผ่าน, บันทึกผู้ใช้ แล้วตอบ `201`
6. หน้าเว็บกลับ IT 02-1 พร้อมข้อความสำเร็จ

## เข้าสู่ระบบ

1. ผู้ใช้กรอกชื่อผู้ใช้และรหัสผ่านใน IT 02-1
2. API ตรวจ hash และออก JWT เมื่อข้อมูลถูกต้อง
3. หน้าเว็บเก็บ JWT ใน `sessionStorage` แล้วเปิด IT 02-3
4. IT 02-3 เรียก `/api/auth/me` พร้อม bearer token
5. API ตรวจ JWT แล้วตอบชื่อผู้ใช้; ถ้าไม่ผ่านให้ล้าง token และกลับหน้าเข้าสู่ระบบ
