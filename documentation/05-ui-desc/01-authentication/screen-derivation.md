# การสืบที่มาของหน้าจอ

| หน้าจอ  | Route       | ต้นทาง   | หน้าที่                                           |
| ------- | ----------- | -------- | ------------------------------------------------- |
| IT 02-1 | `/login`    | No2.docx | รับชื่อผู้ใช้/รหัสผ่านและเปิดสมัครสมาชิก          |
| IT 02-2 | `/register` | No2.docx | สมัครสมาชิกและยืนยันรหัสผ่าน                      |
| IT 02-3 | `/welcome`  | No2.docx | แสดง `Welcome User: {username}` หลัง API ตรวจ JWT |

ภาพในโจทย์กำหนดองค์ประกอบและลำดับงาน ไม่ได้บังคับให้ลอก wireframe จึงออกแบบใหม่เป็น Secure Access UI ระดับองค์กร โดยคงชื่อหน้าจอ ฟิลด์ ปุ่ม และลำดับงานตามต้นทาง
